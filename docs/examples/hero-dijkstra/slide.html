Dijkstra’s Algorithm: Worked Example

Find the cheapest path from A to F.
Edges are undirected; weights are costs.

  1. Set dist[A] = 0; every other vertex ∞.
  2. Settle the unsettled vertex with the smallest dist.
  3. Relax each edge (u, v):
    dist[v] = min(dist[v], dist[u] + w)
  4. Repeat until F is settled.
