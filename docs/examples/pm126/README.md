# Engine continuity refinements

These files preserve an intermediate engine presentation experiment. They are development artifacts, not independent learner evidence or a general physical simulation. The original recorded model art and narration are retained; application controls and bounded animation provide the interaction.

Reproduction commands and original source/assumptions are in [the base engine example](../pm121/README.md). Tests under `tests/engine` and `tests/domain/engine-*` cover playback, exact media position, reduced-motion snapshots, cycle comparisons, evidence inspection and saved local studies. The current integrated engine uses a built-in cutaway with Muse-selected placement/poses; it is distinct from these earlier recorded art experiments.

Earlier checks found ambiguous browser selectors, interrupted/recovery paths and missing model-output bindings; subsequent tests retain those cases. Passing rendering/control tests does not establish thermodynamics, actual learning, hosted inference or physical native acceptance. See [current verification](../../VERIFICATION.md) and [third-party notices](../../../THIRD_PARTY_NOTICES.md).
