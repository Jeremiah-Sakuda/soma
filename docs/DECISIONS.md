# Architecture decisions

Current decisions consolidated November 4, 2026. [PRD](PRD.md) owns scope; this record states the reasons behind the implementation.

| Decision | Reason and consequence |
| --- | --- |
| Visual exploration is the primary journey | Start from selected visible context. Earlier semester-workspace routes remain, but connection/setup cannot block exploration. |
| Muse proposes; application code computes | Typed reading/composition lets models interpret and explain while deterministic solvers own numerical consequences. |
| Two checked families | BFS/Dijkstra and ideal DC networks have explicit contracts and independent references. Other subjects remain explanatory until their own model is supported. |
| Independent image review plus blind re-read | Wonder can challenge Spark against the same source; disputed values are corrected only after agreement. Agreement remains fallible. |
| Bounded advisory prose review | One repair/re-review fits existing limits. Numerical results do not depend on a model’s approval. |
| Application-owned follow-up bindings | A question must not restore source defaults or discard the learner’s experiment. Preserve controls, lineage and earlier revisions. |
| Firestore for managed persistence | One owned, versioned record model; local synthetic storage is an explicit development fallback. No separate graph database or agent framework. |
| Transient private capture pixels | Save interpreted data and controls, not private screenshot images. Allowlisted original public recording images are a separate exception. |
| Restricted Electron companion | Native capture, source drawing and lifts reuse the web engine without exposing arbitrary Node or IPC to hosted content. |
| Illustrative engine and authored mechanisms | Muse can choose presentation/poses; built-in engine geometry and motion remain application-owned. No checked thermodynamics claim. |
| Optional Gemini narration | Meta transcription and Spark-authored explanation remain distinct from optional Gemini TTS; manual steps and captions remain usable. |
| Immutable observations | Help, reveals, original attempts and actual time remain separate from revisable learner interpretations. No completion-to-mastery shortcut. |
| Application-enforced budget reservations | Bound calls, time, retries and spend; unknown usage retains its reservation and 20% of actual allocation stays reserved. |
| One canonical repository | `Jeremiah-Sakuda/soma` contains the product and release source. Use current history and normal pushes; do not restore pre-rewrite branches. |
| Local development records | Prompt archives, internal planning and capture material remain ignored rather than becoming public product documentation. |

The notarized 0.5.0 download is pinned to its release tag. Subsequent documentation/readability maintenance on main does not replace or relabel its signed bytes. [Release verification](VERIFICATION.md).
